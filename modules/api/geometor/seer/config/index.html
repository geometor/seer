class geometor.seer.config.Config(config_dir: pathlib.Path | str)¶

Handles loading and accessing configuration from a specified directory.

Expects an ‘index.yaml’ file in the root of the config_dir. Referenced files (instructions, context files) within index.yaml are expected to be relative to config_dir and their content will be loaded into the configuration data.
