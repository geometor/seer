geometor.seer.tasks.tasks.load_tasks_from_kaggle_json(file_path: pathlib.Path) → Tasks¶

Loads tasks from a single JSON file where the top level is a dictionary mapping task IDs to task data (containing ‘train’ and ‘test’ lists).

Parameters:

file_path – The path to the JSON file.

Returns:

A Tasks object containing the loaded tasks. Returns an empty Tasks object if the file is not found, is invalid JSON, or has an unexpected structure.

geometor.seer.tasks.tasks.get_unsolved_tasks(sessions_root: pathlib.Path) → Tasks¶

Scans session summaries to find all unique tasks present across sessions that have never passed the test phase. Loads these tasks from their task.json files.

Parameters:

sessions_root – The root directory containing session folders.

Returns:

A new Tasks object containing only the unsolved tasks found across all sessions. Returns an empty Tasks object if sessions_root is invalid, no tasks are found, or scanning fails.
