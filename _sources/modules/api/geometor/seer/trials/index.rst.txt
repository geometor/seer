   .. py:method:: analyze_trial_data(code_trial_data_list: List[Dict[str, Any]]) -> Dict[str, Any]
      :staticmethod:


      Analyzes a list of CodeTrial data (dictionaries) and returns aggregated metrics.

      This method contains the core logic for calculating best scores, pass status,
      and extracting metrics, intended to be used by both TaskStep.summarize
      and rebuild_step_summary.

      :param code_trial_data_list: A list where each item is a dictionary representing
                                   the data of a CodeTrial (e.g., loaded from JSON
                                   or generated by CodeTrial.to_dict()).

      :returns:

                - best_score: The lowest score among all trials (float or None).
                - any_train_passed: True if any trial passed all its train pairs, else False/None.
                - any_test_passed: True if any trial passed all its test pairs, else False/None.
                - best_trial_metrics: Dict containing detailed metrics from the best trial's train pairs.
                - all_train_results_summary: Dict summarizing all train TaskPairTrials across all CodeTrials.
                - all_test_results_summary: Dict summarizing all test TaskPairTrials across all CodeTrials.
      :rtype: A dictionary containing the analysis results



.. py:class:: CodeTrial(task_step, code_filename: str, code, task: geometor.seer.tasks.tasks.Task)

      Checks if the training trials passed.

      :returns: True if all training trials passed, False if some

   .. py:property:: test_passed
      :type: bool | None


      Checks if the test trials passed.

      :returns:

                True if test trials were run AND all relevant ones passed.

                             None if test trials were NOT run (because train failed)

   .. py:method:: test_code_with_timeout(code, task_pairs, timeout=10) -> dict

      Executes and validates the generated code with a timeout.

      :param code: The Python code to execute.
      :param task_pairs: A list of TaskPair objects to test the code against.
      :param timeout: The maximum execution time in seconds.

      :returns:

                A dictionary containing the results of the code execution.
                    If an error occurs, the dictionary will contain an "error" key
                    with a description of the error.  Otherwise, it contains a
                    "trials" key, with a list of trial results.
      :rtype: dict



   .. py:method:: test_code(code, task_pairs) -> dict

      Executes and validates the generated code.

      :param code: The Python code to execute.
      :param task_pairs: A list of TaskPair objects to test the code against.

      :returns: A dictionary containing the results of the code execution.  If
                an error occurs during parsing or execution, the dictionary will
                contain an "error" key with a description of the error.  Otherwise,
                it contains a "trials" key, with a list of per-pair trial results,
                which are now TaskPairTrial objects.
      :rtype: dict
